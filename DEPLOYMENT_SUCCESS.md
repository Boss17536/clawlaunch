## 🐛 If Deployment Fails

Check Vercel build logs for errors. Common issues:

### Import Errors:
- Ensure all imports use `@/` alias
- Check component names match file names

### ESLint Errors:
- Run `npm run build` locally first
- Fix all warnings

### Environment Variables:
- Add in Vercel dashboard if needed
- Settings → Environment Variables
