## ⚡ Performance Tweaks

### Background Animations
```diff
- duration: 8s, ease: easeInOut, opacity: 30%
+ duration: 12s, ease: linear, opacity: 20%

- scale: [1, 1.2, 1]  (expensive!)
+ x/y only  (cheap!)

+ will-change-transform (GPU hint)
+ filter: blur(40px) (built-in)
```

### Floating Card
```diff
- duration: 4s, ease: easeInOut
+ duration: 5s, ease: linear

- animate: { y: [0, -10, 0], scale: [1, 1.05, 1] }
+ animate: { y: [0, -8, 0] }  (no scale)

+ will-change-transform
```
