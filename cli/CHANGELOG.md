# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-02-09

### Added
- Initial release of Social Poster Free Tier
- Interactive setup wizard with 5 questions
- Support for Twitter/X and LinkedIn platforms
- 5 topic categories with 5 templates each:
  - Motivation
  - Fitness
  - Tech
  - Business
  - Default
- Automatic scheduling using cron
- Timezone-aware posting
- Monthly counter (20 posts/month limit)
- Automatic counter reset on 1st of month
- Browser-based posting via intent URLs
- CLI menu with options:
  - Start Scheduler
  - Test Post Now
  - View Status
  - Reconfigure
  - Exit
- Configuration storage at `~/.social-poster/config.json`
- Full ToS compliance (no automated clicking)
- Comprehensive documentation

### Features
- ✅ 100% ToS compliant
- 🔒 Zero credentials stored
- 📅 Smart scheduling (1-5 posts/week)
- 🆓 Free tier with 20 posts/month
- 🌍 Timezone support (9 major timezones)
- 🎨 Pre-written templates
- 🧪 Test mode for immediate preview

### Security
- No password storage
- No API keys required
- Local-only data storage
- Manual user action required for posting

### Supported Platforms
- Twitter/X (via intent URLs)
- LinkedIn (via share URLs)

### Free Tier Limits
- 20 posts per month
- 1 platform only
- Max 5 posts per week
- Pre-written templates (no AI)
- 1 social account
