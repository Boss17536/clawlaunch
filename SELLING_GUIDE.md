## 🛡️ Security Features:

### **How the limits work:**
1. **Machine Fingerprint** - Tied to user's computer
   - Hostname, CPU, RAM, username = unique ID
   
2. **Encrypted Tracking** - Can't manually edit
   - Files stored in `~/.social-poster/`
   - Encrypted with machine-specific key
   
3. **Multiple Verification Layers**
   - License file
   - Usage file
   - Machine fingerprint file
   - All cross-verified

### **Can users bypass?**
- ❌ Deleting config files won't work (machine fingerprint remains)
- ❌ Editing JSON won't work (encrypted)
- ❌ Changing system clock won't work (dates are verified)
- ⚠️ Reinstalling OS or buying new computer = new machine (will work)

**Good enough?** Yes! 95% of users won't try to bypass. Focus on value, not perfect security.
